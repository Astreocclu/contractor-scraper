# Batch C Swiss Rankings Summary

## Method
- 100 contractors scored holistically (Task tool Opus agents)
- 253 Swiss-seeded pairwise comparisons (Task tool Sonnet agents)
- 5+ comparisons per contractor (min: 4, max: 6, avg: 5.1)
- Average score diff per matchup: 3.0 (tight pairing)
